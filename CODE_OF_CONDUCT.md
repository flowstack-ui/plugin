# Contributor Covenant Code of Conduct

We are committed to a respectful, harassment-free community. Be constructive,
assume good intent, respect privacy and intellectual property, and focus review
on the work rather than the person.

Unacceptable behavior includes harassment, discrimination, threats, publishing
private information, or deliberately sharing paid or confidential source.
Repository maintainers may edit or remove contributions and restrict
participation when necessary to protect the community.

Report conduct concerns privately to the repository maintainers through the
FLOWSTACK UI GitHub organization.
