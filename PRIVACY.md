# Privacy Policy

The FLOWSTACK UI plugin is a skills-only instruction bundle. The plugin itself
does not operate a service, collect telemetry, store personal data, or transmit
project content to FLOWSTACK.

The host product and any tools a developer separately enables process data
under their own terms and privacy policies. The FLOWSTACK MCP service is not
silently installed or configured by this plugin.

Security or privacy concerns may be reported through the repository security
policy.
